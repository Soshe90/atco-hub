# ATCO Hub link

Forwards to the current address of the ATCO Hub test server. That address changes whenever the server's tunnel
restarts; the server updates `link.json` here automatically. The app itself is not in this repository.

- `https://soshe90.github.io/atco-hub/` opens the app.
- `https://soshe90.github.io/atco-hub/?install` shows how to add an icon to the home screen that always finds the app.
